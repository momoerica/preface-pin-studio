PROPOSED ARCHITECTURE / NOT REVERSE ENGINEERING

从真实产品到可追踪发布

以下为 PREFACE 的建议架构，不是 block2pin 内部实现。v3 仅可选本机 Apple Vision 识图后端；没有 Pinterest API。用户拼写 block2pin 尚未确认；公开检索候选为 BlogToPin（https://www.blogtopin.com）。微信文章受验证码阻断未读。参考输入→品牌模板→编辑→画板/日期→本地计划→CSV 的流程，不是复刻原工具。官网功能仅为厂商宣称，未登录验证；Facebook 标注 Coming soon，未验证有公开开发者 API。

01　操作 UI → 素材选择 / 草稿 / 画布与属性
02　产品与素材库 → 已核字段 + 来源路径 + 原图只读
03　内容生成器 → 当前规则模板；未来可替换 LLM，不能擅增产品事实
04　审核状态机 → 草稿 → 已批准 → 本地队列 → 手动发布记录；变更撤销批准
05　排程与导出 → 当前本地 PNG / 文案 / JSON / 计划 CSV，未来 worker 可靠执行
06　Pinterest adapter：未接通 → 未来 OAuth 最小授权，服务端保管 token，显式授权后发布
07　真实数据导入 → 官方 CSV / API → 来源校验 → 复盘，当前无数据

建议部署边界

Node + SQLite + 本地文件库 + workers。OAuth 密钥与令牌只放服务端，浏览器不持有密钥。抓取需 SSRF 防护、白名单与大小限制；上传校验 MIME、签名与像素数量；任务幂等、失败重试、审计日志。默认不开通付费、广告或自动发布。
